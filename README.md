## 🧊 System Architecture: The Mission
UK politics isn't broken because it's complicated; it's broken because the UI is terrible. **@properrainy** is an educational hub designed to overhaul how British governance and policy are consumed. 

We take 400-page dense whitepapers and archaic House of Commons debates and run them through a high-fidelity visual translator. No partisan spin. Just pure, hyper-legible data for the modern UK voter.
